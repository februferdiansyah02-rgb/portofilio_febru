# FEB.ID — Personal Portfolio

A personal portfolio website showcasing my profile, skills, projects, and experience as a Computer Science student with an interest in Front-End Development, Back-End Development, Database Management, and UI/UX Design.

This website is designed with a modern, minimalist, and futuristic interface using a dark visual theme, smooth animations, and interactive elements.

## 🚀 Tech Stack

This portfolio is built using the following technologies:

- **React.js** — JavaScript library for building interactive user interfaces.
- **Vite** — Frontend build tool for fast development and optimized production builds.
- **Tailwind CSS** — Utility-first CSS framework for responsive and modern styling.
- **JavaScript (ES6+)** — Main programming language for application functionality.
- **HTML5** — Structures the content of the website.
- **Lucide React / React Icons** — Icon libraries for interface elements.
- **GSAP** — Animation library for creating smooth and interactive animations.

## ✨ Features

- Personal introduction and profile.
- About Me section.
- Skills and technology showcase.
- Interactive project showcase.
- Responsive website layout.
- Smooth animations and transitions.
- Social media and contact links.
- CV download.

## ⚙️ Installation & Setup

Clone this repository:

```bash
git clone <repository-url>
```

Navigate to the project directory:

```bash
cd portofilio_febru
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
